# 亮哥盲派命理框架 · 实用工具箱

> 融合段建业体系核心方法论与杨清娟体系十大口诀，两套盲派真传合一。
> 不看旺衰、不寻用神、不讲格局——只看做功。

---

## 一、八字入手法（段建业法）

### 1.1 第一步：找功在何处

八字排定，从日柱入手，按顺序排查四柱的「做功」：

1. **先看日干** — 有无合（合财/合官）、有无生（伤官/食神贴身）
2. **次看日支** — 与它支刑冲克害合墓库
3. **再看禄神、比劫** — 位置与做功情况
4. **定主** — 日干做功则以日干为主；日支做功则以日支为主；日柱共同做功则以日柱为主

> ⚠️ 杨清娟补充：日干无合无生，弃日干不看，专看日支是否成党成势。
>
> 口诀：「日干有合看日干，日干无合看日支，日支无功看禄神。禄神无功，寻常百姓。」

### 1.2 做功的六种方式

| 类型 | 核心 | 例 |
|------|------|----|
| **制用结构** | 体制用 | 比劫制财、伤官制官、印星制食伤 |
| **化用结构** | 印化官杀 | 杀生印、印生身——化凶为用 |
| **生用/泄用** | 伤食生财、伤食泄秀 | 内食神做企业 |
| **合用结构** | 日主合财/合官 | 合财讲身强弱，合官讲功 |
| **墓用结构** | 入墓=得到/控制/管理 | 官墓、财库入主位 |
| **复合结构** | 多种做功并存 | 一命多途，随时间转换 |

**杨清娟补充**：制用结构占比最大。合制财官的人动脑子，冲制财官的人是莽汉。合是和谐地得到，冲有成就感，穿两败俱伤。

## 二、宾主体用（段建业体系核心）

### 2.1 宾主分层

| 层次 | 主 | 宾 |
|------|----|-----|
| 第一层 | 日主 | 他干支 |
| 第二层 | 日柱（自己家） | 年、月、时柱 |
| 第三层 | 日时（自己+孩子家） | 年月（父母/社会） |
| 第四层 | 四柱八字 | 大运、流年（外来） |

> **杨清娟口诀**：「主位得用是真得，宾位得用要看合。财官在主位，是自己的；财官在宾位，是别人的。」

### 2.2 体用十神分类

| 体（工具/自身） | 用（目的/追求） |
|---|-----|
| 日主、印星、禄神、比劫 | 财星、官杀星 |
| 食神（偏体） | 伤官（偏用） |

**口诀**（杨清娟）：「体不动，用不来，人生无作为。废神多，功神少，一生瞎忙活。」

### 2.3 功神与废神

- **功神** — 参与刑冲克穿合墓的字
- **废神** — 不参与做功的字
- 成功者：功神多而废神少，或功神虽少但效率奇高
- 平庸者：废神多功神少，或有功神但效率低

## 三、干支配置原理（段建业）

### 3.1 干支生克

- 天干可克地支，地支不可克天干（君臣关系）
- 例外：天干与地支自合（丁亥、己亥、辛巳、癸巳、壬午、甲午、戊子等），此时地支可合克天干

### 3.2 干支互通（原身与禄）

| 天干 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |
|------|----|----|----|----|----|----|----|----|----|----|
| 禄 | 寅 | 卯 | 巳 | 午 | 巳 | 午 | 申 | 酉 | 亥 | 子 |

- 丙戊半通禄，丁己半通禄
- 未中有丁火，丁见未为半个禄；癸见丑为半个禄
- 辰戌丑未无原身（四墓库特有）

> 杨清娟补充：「天干虚透，应期要地支出来。地支遁藏，应期要天干透出。」

### 3.3 虚实原理

- 实：天干有根有生
- 虚：天干无根无生
- 虚是一种弱化、轻化、气化的存在状态
- 应期：虚者逢其实（大运通根见实）则反常；实者逢其虚（虚透天干）亦反常

## 四、制法与效率（段建业 + 杨清娟）

决定八字富贵等级的核心——**效率**。

### 4.1 合制效率排行

1. **巳申合** ← 效率最高（金水制巳、木火制申均可制死）
2. **卯戌合、卯申合、午亥合** ← 次高
3. **卯未合、亥未合** ← 效率较低
4. **午未合** ← 两字相生，无制

**杨清娟专论：辰酉合真义**
> 辰酉合不是辰生酉，是**铲断辰中乙木**。
> - 乙木为根时，辰酉合铲断，枭神夺食，破财/伤身体
> - 乙木为竞争对手时，辰酉合铲其根，利于竞争
> - 辰酉合闭官杀库，与官方无缘（除非壬水透出）
> - 辰酉合加强酉的力量，酉为财则发财，酉为禄则禄旺

### 4.2 冲制/刑制效率

- **丑未冲、辰戌冲、丑戌刑** ← 冲库刑库效率最高
- **寅申冲、巳亥冲** ← 次高
- **子午冲、卯酉冲** ← 略低，需一方之势远大于另一方
- 力量相当为冲起，力量相差为冲动，库与库相冲为冲毁
- 实体冲能得到，虚的冲冲散了冲跑了

### 4.3 克制效率

- **单纯克制**（如戌克亥）效率低，只能出普通人
- **围克**（包围制之）效率最高——被制之神无处可遁

### 4.4 穿制

- 可相穿的六组：**酉戌穿、卯辰穿、子未穿、丑午穿**
- 不可相制（相生）：申亥穿、寅巳穿
- 穿的力量大，效果明显，且互相伤害
- **口诀**（杨清娟）：「冲有成就感，穿两败俱伤，合是和谐地得到」
- 穿坏禄：贫穷、卑微、身体有病。穿坏比劫：朋友无助、克兄弟姐妹

### 4.5 暗合（杨清娟专论）

- **寅丑暗合** — 表面寅木克丑土，实际寅中丙火合制丑中辛金（丙辛合），表面一套背后一套
- **卯申暗合** — 申中庚金合制卯中乙木（乙庚合），就一件事
- **午亥暗合** — 表面亥水克午火，实际亥中壬水合制午中丁火（丁壬合），表面一套背后一套

## 六、应期法则（段建业+杨清娟）

### 6.1 三种应期

1. **原字应期** — 八字中某字在流年/大运中出现，或见其禄神与原身
2. **藏干应期** — 地支遁藏之字在天干出现
3. **冲合应期** — 原局有合，以冲为应；原局有冲，以合为应

### 6.2 六种作用应事

| 作用 | 含义 |
|------|------|
| 合者 | 主到 |
| 冲者 | 主动 |
| 墓者 | 主收 |
| 穿者 | 主伤 |
| 刑者 | 主讼/手术/伤害 |
| 破者 | 主不完整/针尖对麦芒 |

### 6.3 调候法则（杨清娟专论）

- 调和命局中五行之偏枯
- 方法：用一吉神冲去/刑去坏星（不能用穿）；用一神星把吉神合回来
- 例：冬天的戊土喜欢丙火，夏天的戊土喜水调候

> **口诀**：「调候就是把命局坏的星，用一个吉神把它冲刑去，或用一个神星把命局中的吉神合回来。」

### 6.4 三合局干扰星（杨清娟专论）

- 三合局有干扰星（中神长生被穿或合）
- 干扰星不意味着合局解散，只是合局受阻
- 三合局不怕冲，冲不解合局

## 八、综合断命流程

```
八字排定
    ↓
第一步：竖排八字，定年月日时
    ↓
第二步：定宾主（谁是自己，谁是别人）
    ↓
第三步：定体用（什么是工具，什么是目标）
    ↓
第四步：找做功（日干→日支→禄神→比劫）
    ↓
第五步：辨制法（合/冲/刑/穿/克/墓/暗合）
    ↓
第六步：看效率（制法高下决定富贵等级）
    ↓
第七步：评富贵（势+功=大富贵；只有功无势=普通人；无功=差命）
    ↓
第八步：断应期（大运流年与原局作用）
```

## ⚠️ 敏感判断检查点

> 本框架涵盖婚姻、伤病、牢狱等敏感专题。在输出任何敏感判断结论前，必须先完成本检查点。

### 检查流程

在输出婚姻/伤病/牢狱/财禄等敏感判断前，必须：

1. **先问用户确认**：
   - 婚姻判断前 → 「需要详细分析婚姻/感情运势吗？此内容较为敏感」
   - 伤病判断前 → 「需要详细分析健康/伤病风险吗？此内容较为敏感」
   - 牢狱判断前 → 「需要详细分析官非/牢役风险吗？此内容较为敏感」
2. **用户确认后** → 再输出详细判断（包含具体结论和应期）
3. **用户未确认时** → 只输出「框架性结论」（如：婚姻需注意XXX，但不给出具体结论和应期）

### 框架性结论模板（未确认时使用）

| 专题 | 框架性结论（不输出具体） |
|------|------------------------|
| 婚姻 | 「配偶宫/感情线存在隐患，需注意XX年」 |
| 伤病 | 「XX系统需关注，建议XX季节注意」 |
| 牢狱 | 「官非结构存在，需注意XX运/流年」 |
| 财禄 | 「财库配置+做功效率提示：XX」 |

### 敏感专题判断标准

**婚姻**：未土配偶宫被冲/亥日支被冲穿 → 感情线有隐患 → 具体结论须用户确认

**伤病**：亥申穿/丑午穿/子未穿 → 相应身体部位有问题 → 具体结论须用户确认

**牢狱**：食神不自由/杀无制/穿官 → 官非结构 → 具体结论须用户确认

## 十、亮哥命盘专题验证（杨清娟案例交叉分析）

> 本章以亮哥命盘（壬戌 癸丑 辛亥 乙未）为主线，从杨清娟案例 51-187 中寻找相似/相反结构进行交叉验证。每个专题均包含：命理规律 + 杨清娟案例印证 + 亮哥自我验证。

### 亮哥命盘基础档案

**八字**：壬戌 癸丑 辛亥 乙未（乾）

**大运**：丁巳（当前，巳亥冲，变动期）

**流年**：丙辰（丙辛合，辰冲戌）

**命局结构速览**：

### 10.1 婚姻专题——未土配偶宫与亥日支的双重分工
